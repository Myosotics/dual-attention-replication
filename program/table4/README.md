# Table 4：数据处理、结果与汇报说明

## 一、用到哪些数据？

先理解三个词：**系数**表示注意力与随后收益的关系方向；负数表示注意力较高时随后收益往往较低。**控制变量**用于尽量排除其他市场背景的影响。**代理指标**测量相关现象，但不等于原论文指标。

| 数据 | 通俗含义及来源 | 当前用法 |
|---|---|---|
| ARA | 散户关注股票的程度；作者公开数据，见[作者数据页](https://sites.google.com/site/linpengbaruch/data) | 直接使用，不替换。 |
| AIA期权代理 | 机构阅读行为原数据未取得；现有数据来自[Cboe指数期权统计](https://www.cboe.com/us/options/market_statistics/historical_data/) | 用异常期权成交活跃度代理信息关注，不能直接认定为机构关注。 |
| 市场收益及未来收益 | 市场今天、随后几天涨跌多少；[Luke Stein公开CRSP教学样本](https://lukestein-classes.github.io/fdap/data/) | 使用标普500范围的市值加权、不含现金分红收益，代替论文全市场组合。 |
| VIX | 市场预期未来波动多大，常称“恐慌指数”；Cboe | 使用真实日度值。 |
| AbnTurn成交量代理 | 今天交易是否比平时活跃；Yahoo Finance的SPY历史成交量 | 替代原个股市值加权的异常换手率。原始JSON已在数据ZIP内保存。 |
| ΔEPU代理 | 政策消息的不确定性是否变化；[PolicyUncertainty](https://www.policyuncertainty.com/) | 使用七日均值的一阶差分，代替原始日度差分。 |
| ΔADS | 经济运行是在改善还是变差；[费城联储ADS](https://www.philadelphiafed.org/surveys-and-data/real-time-data-research/ads) | 真实指数的一阶差分，但当前版本可能修订历史值。 |
| BW情绪 | 市场整体偏乐观还是悲观；Baker–Wurgler公开工作簿 | 采用已生成的SENT月度滞后近似，另两列原值只备查，不重复加进回归。 |
| TMS、DFY | 长短期国债利率差、不同信用评级债券利率差；Goyal–Welch公开月度表 | 控制经济和信用背景；不是股票借券费用。 |

全部输入来自仓库根目录的数据ZIP，不需要联网下载，也不读取暂存的模拟列。具体原始文件、来源链接和构建代码仍保留在各数据目录。共同分析期为 **2010-02-01—2019-10-04，2,437个交易日**；不能将ARA本身更长的覆盖误当作本次回归样本。

此外，本表使用 `mnews26/`：由[美联储FOMC](https://www.federalreserve.gov/monetarypolicy/fomc_historical.htm)、BLS非农与PPI的真实公告日重建，表示未来第2—6个交易日内是否有重大宏观消息，1=有，0=无。

## 二、对数据做了什么？为什么可以这样处理？

### 1．替换及计算

| 处理 | 构建方式 | 为什么尝试替换，以及保留什么差异 |
|---|---|---|
| AIA→异常指数期权量 | 当天期权量÷此前30个交易日期权量中位数−1 | 基金、养老金等机构需要管理一篮子股票的整体风险，指数期权可用于组合对冲和调整市场敞口。因此，当它们更关注宏观消息、重新评估市场风险时，相关交易可能增加；用“比平时多多少”提取这种异常活动。但这是机构参与交易→可能反映关注的间接推断，不能从总量识别机构，也未证明成交主要来自机构，详见下方展开。 |
| 全市场收益→标普500收益 | 读取现有vwret.csv；已经是百分数，不再乘100 | 两种组合都按市值突出较大公司的影响，也都会受到美国整体经济与市场消息推动，所以标普500可保留“市场共同涨跌”的主要含义，而非随便选一只股票代替市场。但它更偏大盘股，缺少全市场的小盘、低流动性公司，且现有收益不含现金分红，因此系数和显著性可能改变。 |
| 未来一周收益 | 先在完整交易日历上，将未来第2—6个交易日收益复合：`100×[∏(1+r/100)−1]` | 先固定“观察今天、解释随后哪几天”的时间关系：不把当天或紧接的第1日混入论文第2—6日窗口。复合收益表示连续持有这5个交易日的累计涨跌，不能简单把百分数相乘。预测窗口沿用论文，市场来源仍为标普500代理；与已有fvwret5.csv逐日校验，不是为了接近原结果而生成随机收益。 |
| 异常换手率→SPY异常成交量 | 当天对数成交量−此前252个交易日对数成交量均值 | 换手率=成交量÷流通份额；取对数后，异常换手率等于异常成交量减去份额变化的影响。若份额在历史窗口内较稳定，成交量突然增加与换手率突然增加有相近含义；再减去历史均值，排除通常交易规模的影响。SPY跟踪广泛的大盘股票，适合提供市场活跃度近似，但ETF申赎会改变份额，且存在套利交易，也不是原个股市值加权汇总。 |
| 日度ΔEPU→七日均值差分 | `EPU_MA7(t)−EPU_MA7(t−1)`，t−1为前一个自然日 | 输入本身仍是同一类政策不确定性指数，只是先做了七日平滑；今天减昨天仍在衡量不确定性上升还是下降，而不是把另一个无关变量塞进模型。但平滑后的变化更缓慢，会削弱单日冲击、改变时点，不能恢复原始日差分。因此仅作为同一经济背景的较平滑控制。 |
| 月度数据→日度控制 | TMS、DFY使用前一日历月值；BW文件已滞后一个月，不再重复滞后；沿用最长40个自然日 | 经济利差与情绪控制的含义没有改变，改变的是何时将月度观测用于日度回归。假设这类背景状态在短期内相对缓慢变化，使用上月值可以近似当前背景，并避免明显使用当月尚未结束的信息。沿用不等于每天重新观测，40日只是防止长期缺口无限填补；实际发布时间及历史修订仍未完全核验，不能声称严格实时策略。 |

代码先在完整股票交易日历上生成VIX、收益、AbnTurn的当期与1—4阶滞后，再筛选样本；不跨删除的日期移位。上述代理有经济上的共同含义，但未证明与作者指标等价。

### AIA替代的关键idea：为什么想到指数期权？

**先纠正两个容易混淆的概念：这里用的是“指数期权”，不是期货；“一天总成交量大”也不等于识别到了“大额机构订单”。** 当前CSV只有每日汇总量，没有每笔订单大小和交易者身份。

可以按下面这条链向听众解释：

1. **机构管理的是整个股票组合。** 例如，一家基金持有许多只股票，担心宏观政策变化会让整个市场下跌。逐只股票减仓不一定方便，可能通过指数看跌期权给组合买“保险”；也可能通过其他期权策略调整市场方向或波动率敞口。
2. **这类需求让指数期权市场成为观察机构活动的一个窗口。** Cboe的2019年年报列举了养老金使用SPX看跌期权对冲、资产管理者使用备兑看涨策略、对冲基金交易风险溢价等用途。这说明“机构会使用指数期权管理组合”有事实依据，但不能据此断言全部指数期权成交、或某天增加的成交，主要属于机构。[Cboe 2019年报](https://www.sec.gov/Archives/edgar/data/1374310/000155837020001127/cboe-20191231x10k3d7487.htm)
3. **我们的研究假设是：更关注信息，可能伴随更多交易调整。** 机构更重视某条宏观消息时，可能重新评估组合风险，并调整期权头寸。因此，“异常活跃的指数期权交易”可能包含机构信息关注的信号。这一步是本组采用代理的推理，不是已验证的因果关系。
4. **为什么看异常量，而不是原始量？** 市场平常就有大量交易，长期规模也会变化。用当天成交量除以此前30个交易日中位数，再减1，是比较“今天比近期正常水平多多少”。例如，平常200万张、今天300万张，则代理为0.5，即高出50%；这不是说机构关注提高了50%。
5. **原AIA与本代理观察的是两个环节。** 原文Bloomberg指标更直接记录机构的信息阅读／关注；我们记录交易反应。关注后未交易会被漏掉，例行对冲、投机、到期换仓和做市交易又可能增加成交，却未必代表新增信息关注。个人投资者同样参与指数期权，SPX只是用途例子，不能把SPX的投资者结构直接推给本组indexpc指数期权汇总数据。2018年的S&P资料也明确提到个人和机构都会使用SPX。[S&P 2018年说明](https://www.indexologyblog.com/2018/07/17/growth-in-use-of-sp-500-options-at-cboe-over-35-years/)

**可直接用于汇报的表述：**“我们考虑到机构需要用指数期权管理整个股票组合，重大市场信息可能促使它们调整交易，所以用异常指数期权成交量作为可能包含机构关注信号的间接代理。它并未识别出机构身份，也不等同于阅读行为，因此这里检验的是交易活动代理与回报的关系。”

避免表述为“期货交易量大，所以就是机构关注高”。本组未取得机构成交占比、机构专用流量或Bloomberg AIA，尚不能验证该代理究竟捕捉了多少机构注意力；已有回归不显著也不能据此否定原AIA。

### 2．删去了什么？

**AbnNews异常新闻量从共同控制项中省略。** 它指“今天有关股票的报道比平时多多少”，用来区分关注变多与新闻确实变多。原口径需要历史报道、股票标签、计数和权重等RavenPack输入；本组尚未取得权限与完整历史覆盖。代码的`CONTROL`列表不含AbnNews，绝不读取随机模拟列。

因此，当前是**减少新闻控制、采用代理的回归**，不能说已排除新闻密集度的影响，也不能称为原表全控制复现。原模拟文件未删除，保留在数据ZIP的`未采用模拟_暂存/`。

### 3．宏观窗口怎么做，为什么取消All News？

**宏观窗口重建的idea：** FOMC议息、非农就业和PPI物价报告都可能改变对利率、经济与通胀的判断，因此保留这些“重大宏观信息集中公布”的时点，能继续研究关注与公告前后回报的关系。这里用的是公告日期是否落入未来窗口，不是猜测消息利好还是利空；也没有声称三类公告代表所有重要新闻。用真实官方日期重建保留了事件含义，但作者的事件筛选和休市处理仍可能不同。

代码读取已构造的mnews26，不根据回归结果移动公告日，也不为匹配论文N调整日期。实际为Yes 1,324日、No 1,113日；原始日期的休市处理和作者具体筛选可能不同。

All News原本还要判断公司财报公告是否密集，例如当日公告公司的市值占整个市场的比重。完整历史财报实际公告日、当期公司覆盖和历史市值未补齐，今天的标普500名单也不能代表历史名单。因此代码只输出Macro News，不读取或模拟All News。宏观窗口不能冒称“全部新闻”。

## 四、怎样运行、怎样看CSV？

在仓库根目录安装依赖（一次即可）：

```bash
python -m pip install numpy pandas scipy statsmodels
```

运行本文件夹唯一的代码文件：

```bash
python program/table4/run.py
```

默认读取根目录 `group3_collected_data_v14.zip`，不必解压。也可指定ZIP或解压后的数据根目录：

```bash
python program/table4/run.py --data /path/to/data.zip
```

代码是独立文件，不依赖program里的其他Python文件。运行后只写入本目录的 `result/` CSV，并在终端打印关键系数和p值。结果CSV可用Excel/WPS直接打开，使用UTF-8 BOM；每列表示一种回归模型或分组。修改输入后结果可能改变，下文数字仅对应本次已保存结果。

**读表词典：**N=实际观测日数；adj. R²=模型解释程度的一项指标；方括号为t值；*、**、***分别表示10%、5%、1%水平。没有星号不证明“绝对没有关系”，而是当前数据证据不足。1bp为0.01个百分点。“1标准差效应”是把注意力的一次典型幅度变化换算成收益基点，便于比较；代理定义不同，不能只比较原始系数大小。

可用 `--bootstrap-reps 1000` 修改重抽样次数；0表示不运行，此时Boot行会标注not run。默认结果用500次，固定种子保证重复运行一致。
