# Table 2

运行 `python program/table2/run.py`，默认读取根目录v14数据ZIP。

- `results.xlsx`：Panel A ARA 8列、Panel B AIA代理9列，控制系数与NW(30) t值逐行展示。

- `coefficients_long.csv`：全精度系数、标准误、p值和NW置信区间；`key_results.csv`为关键列。
- `sample_audit.csv`：各模型样本数、起止日期。
