## 替代与重建指标的简短依据

以下理由支持尝试代理或重建，不代表已验证与原指标等价，也不保证回归结果一致。模拟占位列不属于这类替代。

| 指标 | 依据与主要差异 |
|---|---|
| `aia_option_proxy` | 指数期权成交活跃度可间接反映市场信息关注，但不能直接识别机构注意力；与Bloomberg阅读行为指标不同，仅作探索性代理。 |
| `vwret_proxy` | 标普500收益与全市场收益都衡量美国股票市场共同涨跌；覆盖偏向大盘股，不能代表原CRSP全市场组合。 |
| `lBWx_monthly_proxy` | 沿用BW投资者情绪指数并滞后一个月，保留情绪控制含义；不保证等同作者变换，日度映射及实际发布时间仍需核对。 |
| `fvwret5` | 按已有日收益率复合计算未来第2—6个交易日回报，保持论文预测窗口；属于收益率来源替换，不是模拟未来收益。 |
| `dEPU_proxy` | 七日均值差分仍反映政策不确定性变化；平滑削弱短期波动，不能等同原始日度指数差分。 |
| `AbnTurn_volume_proxy` | 异常成交量与异常换手率均反映相对历史水平的交易活跃度；份额稳定时更接近，但SPY份额变化及ETF交易使其不等于市场个股加权换手率。 |
| `mnews26` | 用FOMC、非农、PPI真实发布日期重建同一未来交易日窗口，保留重大宏观事件含义；事件筛选和休市处理可能与作者不同。 |
