## 数据使用

- `ARA.csv`：作者公开原始数据，3,903个交易日，2004-07-01—2019-12-31。
- `AIA_option_proxy_替代/`、`vwret_标普500替代/`、`dEPU_proxy/`、`AbnTurn_volume_proxy/`：来源与重建代码在各目录；都是替代口径，不是作者原始指标。SPY原始接口响应以JSON原样保留。
- `fvwret5/`：从现有日收益率计算未来第2—6个交易日复合回报，2,437行，2010-02-01—2019-10-04；收益率输入单位为百分数，不重复乘100。
- `mnews26/`：FOMC、非农、PPI真实发布日期及窗口代码、网页来源和审计；休市日处理及与论文样本数的差异见目录说明。
- `funding_stress_state/`：TED原始CSV、分组代码与填补审计。3,903日中原缺失100日，沿用过去值最多7自然日（本样本最长5日），同时保留不填补分组。固定全样本中位数为0.32个百分点；这是融资压力扩展，不是借贷费用。
- VIX、ADS、BW、TMS、DFY的公开输入和输出保留；BW原值等备查项不是额外必须加入的独立控制。月度到日度的映射须核对发布时间和作者口径。
- 主文 `模拟数据/` 只保留 `abn_news_模拟/` 与 `percentspread_模拟/`，仅用于代码演示；共享生成器保留历史中间量以便重建，不是完整真实回归面板。

先在完整交易日历生成收益、滞后与分组，再按数据覆盖筛选样本。代理和模拟不能保证得到原论文的系数、显著性或样本量；当前仅整理数据，未重新估计回归。依赖见 `requirements.txt`；所有文件校验值见 `SHA256SUMS.txt`。

## 替代与重建指标的简短依据

以下理由支持尝试代理或重建，不代表已验证与原指标等价，也不保证回归结果一致。模拟占位列不属于这类替代。

| 指标 | 依据与主要差异 |
|---|---|
| `aia_option_proxy` | 指数期权成交活跃度可间接反映市场信息关注，但不能直接识别机构注意力；与Bloomberg阅读行为指标不同，仅作探索性代理。 |
| `vwret_proxy` | 标普500收益与全市场收益都衡量美国股票市场共同涨跌；覆盖偏向大盘股，不能代表原CRSP全市场组合。 |
| `lBWx_monthly_proxy` | 沿用BW投资者情绪指数并滞后一个月，保留情绪控制含义；不保证等同作者变换，日度映射及实际发布时间仍需核对。 |
| `fvwret5` | 按已有日收益率复合计算未来第2—6个交易日回报，保持论文预测窗口；属于收益率来源替换，不是模拟未来收益。 |
| `dEPU_proxy` | 七日均值差分仍反映政策不确定性变化；平滑削弱短期波动，不能等同原始日度指数差分。 |
| `AbnTurn_volume_proxy` | 异常成交量与异常换手率均反映相对历史水平的交易活跃度；份额稳定时更接近，但SPY份额变化及ETF交易使其不等于市场个股加权换手率。 |
| `mnews26` | 用FOMC、非农、PPI真实发布日期重建同一未来交易日窗口，保留重大宏观事件含义；事件筛选和休市处理可能与作者不同。 |
| `funding_stress_state` | TED利差反映信用和融资压力，可能影响套利资金；用于新的融资压力分组，不等于股票借贷费用，不能验证原高费用组−75.70bp。 |
